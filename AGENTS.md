# AI-HUB engineering guidance

Follow the [canonical simplicity policy](https://github.com/bojinda/aihub-gpu-runner/blob/codex/system-estop-e1-20261111/AGENTS.md) and its roadmap.
Use the simplest correct existing mechanism; prefer approved coordinated upgrades over obsolete-version compatibility. Preserve ownership, stale-write/data-integrity/authentication protections. Production changes require explicit authorization.
